# RC24 Video Creative Desk

Статический creative helper для работы с 12 автомобилями, 12 локациями, 7 Porsche-видеореференсами и 12 необязательными черновыми идеями.

## Локальный запуск

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:4173/`.

## Публикация

Сайт не требует сборки. GitHub Pages может публиковать содержимое корня ветки `main` напрямую.
